# Tennis for Two — электрическая реконструкция

Самостоятельный браузерный прибор, версия 0.8.4. Вычислитель мяча, пассивное питание, транзисторный переключатель изображения и электрическая макромодель осциллографа работают в одном расчёте ngspice/WebAssembly. Браузер рассчитывает луч, люминофор и стекло. Planck.js рассчитывает механику ручек и кнопок. Компьютерные игроки управляют обычными входами прибора.

## Запуск

Распакуйте архив и выполните из этой папки:

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080/ . Готовый WASM и локальные зависимости приложены. Для работы требуются JavaScript, WebAssembly и Worker. Экран использует WebGL2 при наличии, иначе работает CPU. Папку также можно разместить на обычном статическом HTTP-сервере.

Режимы: «Я и Противник», «Я и Лиса» (два человека), «Гремлин против Лисы» (два CPU). Механика и стекло включены по умолчанию. RU/EN меняет язык интерфейса с сохранением состояния схемы.

## Необязательное демо с реальным темпом

В архив входят скрипт записи, кодек и воспроизводитель. Готовая запись объёмом 43 МБ вынесена из исходного комплекта.

При наличии Node.js 24 выполните:

```sh
node tools/record-demo.mjs
```

Скрипт рассчитает настоящую схему, действия CPU и механику пультов, затем сохранит запись без потерь: минимум 30 секунд и естественное завершение розыгрыша в `app/demo/`. Обновите страницу: появится дополнительный режим «Демо», выключенный по умолчанию. Он воспроизводится с темпом 1,00×; луч, люминофор и стекло рассчитываются во время просмотра. Запись занимает больше времени, чем воспроизведение. Для статического хостинга подготовьте её до загрузки папки на сервер.

## Исходники и проверки

- `app/`: читаемые JS-модули, SPICE-схемы, локальные зависимости, лицензии и исходные материалы зависимостей.
- `tests/`: проверки электрической модели, механики, оптики, Worker и воспроизведения; браузерный стенд CPU/GPU.
- `tools/build_solver.py`: пересборка оптимизированного WASM из приложенных исходников и наших правок.
- `tools/record-demo.mjs`: создание необязательной записи.
- `tools/study_supply_divider.py`: повторение расчёта статического делителя питания.
- `app/docs/research.html` / `research.en.html`: полное исследование, схемы и источники.
- `app/docs/Gremlin_Tennis_Research_0.8.4.pdf` и английская версия: актуальные PDF.
- [Повторение исследования](REPRODUCING.ru.md): команды, зависимости и области проверок.

`npm test` запускает базовые численные проверки. Другие наборы перечислены в package.json. Установка npm-зависимостей для проекта не требуется: браузерные библиотеки приложены, CLI использует встроенные модули Node. Необязательное сравнение с native требует ngspice 45.2; при его отсутствии такие проверки явно пропускаются.

Исходный ZIP собирается командой `python3 tools/package-release.py --output /путь/tennis-for-two-0.8.4-source.zip`. В нём одна копия текущего кода и документов; созданные записи и журналы тестов исключаются. Проверка распакованного комплекта: `sha256sum -c SHA256SUMS` (macOS: `shasum -a256 -c SHA256SUMS`).

## Авторство и границы

Реконструкция основана на опубликованных чертежах и материалах восстановления. Модели компонентов, выбранные параметры, численные ограничения и неуспешные критерии сравнений описаны в исследовании. Исходный прибор 1958 года недоступен для прямой калибровки. Проверки CPU в облаке сохраняют собственную область; M1/Firefox и аппаратный GPU проверяются отдельно.
