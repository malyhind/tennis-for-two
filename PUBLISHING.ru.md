# Публикация в GitLab Pages

В репозитории — самостоятельный прибор, читаемые исходники, схемы, исследование на русском и английском и браузерные стенды. Pages публикует тот же прибор и документы; страница проверок — `checks/index.html`. Исходный проект — часть [Лаборатории Школы Империи](https://games.oopssre.ru/lab/) в составе [Аркадного зала Школы Империи](https://games.oopssre.ru/).

1. Создайте проект GitLab и загрузите **содержимое** папки `tennis-for-two/` в корень репозитория, включая `.gitlab-ci.yml` и `.gitignore`. Сам ZIP и пакет подключения к сайту загружать не нужно.
2. Отправьте файлы в основную ветку проекта. Единственная задача Pages копирует готовые файлы в `public/`: без пересборки решателя, генерации PDF, записи демо или запуска численных тестов. GitLab Pages использует эту небольшую задачу CI для публикации статики. В проекте должен быть доступен runner.
3. Откройте **Deploy → Pages** и скопируйте фактический адрес. GitLab может назначить отдельный уникальный домен; вычислять адрес по названию репозитория не нужно. Для доступа без авторизации проверьте, что у публичного проекта доступ к Pages установлен в **Everyone with access** (для других уровней видимости название может быть **Everyone**).
4. В **Settings → General** укажите этот адрес как сайт проекта. Когда адрес станет известен, добавьте ссылки на игру, проверки и исследование в начало обоих README.

Основной адрес Pages открывает прибор. Остальные страницы доступны по относительным путям:

| Путь | Содержимое |
| --- | --- |
| `checks/index.html` / `checks/index.en.html` | Страница браузерных проверок, RU / EN |
| `app/display-bench.html` / `app/display-bench.en.html` | Интерактивный стенд транзисторного переключателя |
| `tests/scope-check.html` / `tests/scope-check.en.html` | Проверки экрана CPU/WebGL, оптики и резервного отображения |
| `app/docs/research.html` / `app/docs/research.en.html` | Исследование, схемы, источники и ссылки на актуальные PDF |

На странице проверок можно рассчитать 0,25, 1 или 8 секунд настоящей схемы, измерить время работы решателя и скачать результат в JSON. Проверки запускаются по кнопке на устройстве посетителя. Это проверка работоспособности, а не вся численная серия Node. Недоступные проверки WebGL явно помечаются как пропущенные. Результаты на сервер не отправляются.

Чтобы локально открыть именно публикуемую версию:

```sh
python3 tools/build-pages.py
python3 -m http.server 8080 --directory public
```

Откройте http://localhost:8080/checks/index.html . Экспорт работает и в подпапке проекта: ссылки, модули, workers, WASM и схемы используют относительные адреса. Запись демо включается только при её предварительной генерации; в исходном пакете её нет. Живая схема работает без записи.

Папка `public/` исключена из Git. Она содержит игру, готовые документы и сведения о лицензиях зависимостей. Физическая модель и версия игры остаются 0.8.4.
